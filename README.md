# FolioApp

The public website for Folio, a native reader and editor for Markdown, reStructuredText, code, PDFs, and images on iPhone, iPad, and Mac, by BlueTao LLC. GitHub Pages serves it at https://folio.bluetao.com/ (the old address, https://bluetaollc.github.io/FolioApp/, redirects there) with the privacy policy and support page the App Store links to.

Questions and support requests are welcome as issues here.
